# ChatGPT Remote

<picture><source media="(prefers-color-scheme: dark)" srcset="WindowsAgent/assets/rm-mark-dark.svg"><img src="WindowsAgent/assets/rm-mark-light.svg" width="64" alt="ChatGPT Remote"></picture>

通过手机浏览器连接电脑上的 ChatGPT，继续查看对话、发送消息和操作窗口。Windows 端常驻 **C 字环** 托盘图标。

公开下载版本以 [GitHub Releases](https://github.com/LUMIAO9527/ChatGPT-Remote/releases/latest) 为准。

当前版本 **1.2.8**。设置、项目面板覆盖输入区，短状态与回答、草稿入口在输入框上方横向排列，复杂提醒在顶栏下方。网页按会话保存文字与待发送附件；发送绑定原生输入框并回读确认。过程中的工具操作默认折叠为实际操作摘要，正常说明按顺序显示。[下载安装包](https://github.com/LUMIAO9527/ChatGPT-Remote/releases/latest)

电脑托盘面板采用墨白视觉与 C 字环标志：顶部两行状态带（连接地址、当前窗口），中部二维码与 60 秒配对码，底部设备区按数量分档——0 台一整块圆角虚框、1 台通栏主卡、2 台上下通栏、3–4 台四宫格、5 台以上保持尺寸整页滚动。服务状态胶囊显示运行中、已停止、启动中、启动失败、重连中或已暂停，二维码区随状态变为启动或重连主操作。短提示统一沉底，更新页时自动浮在底部功能区上方；面板保持 312×458、16px 外圆角。

桌面交互保持固定位置：移除确认、处理中、失败和重命名共用卡片外框；标题状态与倒计时保留宽度，品牌标志使用纯绿点，设置按钮采用 ChatGPTnx 同款齿轮。配对码轮换只更新配对区域，保留菜单、文字与光标；延迟结果尊重用户后来选择的焦点。名称错误就近显示，“添加设备”定位至配对区；多个控制窗口通过选择框切换，首页状态带始终两行。

面板展开、页面切换、菜单、设备编辑和提示条带有过渡动画。“设置 → 外观 → 界面动效”可独立开关，设备内容切换始终保持卡片位置。

1.1.0 的思考档位按当前账号启用项与当前模型支持项取交集，隐藏的 Max 等档位不会列出。滑杆只显示当前名称，使用细轨道和竖向实心滑块，首末档位对齐轨道两端。拖动只预览，点「应用」后，模型、强度与快速模式合并提交，逐步核对电脑结果。Chrome 隔离页面和独立 Windows 窗口已验证；未操作用户真实 ChatGPT 的模型与强度。[验收记录](docs/MOBILE-REDESIGN.md)

**1.0.4** 手机可回答电脑问卷、查看其他对话的待处理项，并从顶部电脑图标打开窗口画面。模型、思考档位和快速模式可一起预览和应用。修复队列编辑，按发生顺序显示并折叠回复过程。双击 `ChatGPT-Remote-Preview.html` 可查看交互预览。[手机界面与连接说明](docs/MOBILE-REDESIGN.md)

- 更新在“设置 → 版本更新”内完成下载、校验和重启安装。
- 手机发送键在有草稿时用于发送或排队，在空输入且有原生停止动作时显示停止。队列继续、引导、删除和编辑留在输入框上方。
- 设置和项目面板覆盖输入区，模型、画面、帮助与审批按需打开。回答、草稿和发送状态使用输入框上方的小胶囊；草稿详情点开查看。加号选择附件，待发送文件可逐个移除。
- 电脑弹窗显示请求说明和可用的原生选择。审批点选绑定当前窗口与当前请求，完成后回读。
- 切网和回前台会重新连接。控制通道不可用时新操作走 HTTP，文字流中断时定期读取对话快照。
- 输入框下方直接选择电脑原生菜单中的模型，切换时保留手机草稿。
- 画面解码与界面状态更新分开，减少重复布局；远程模式最高 20 FPS，实际帧率由电脑、网络和手机共同决定。
- 控件使用底色、细边框与轻量反馈，减少悬停阴影和手机弹层的背景模糊。
- 紧凑主面板直接显示二维码、配对码、连接地址、窗口与设备。
- 点击托盘图标展开，再次点击收起。启用失焦收起时，切到其他窗口即收起面板。
- 312×458 面板、16px 外壳圆角、ChatGPTnx 的深浅配色与原生磨砂玻璃。
- 标志在深色背景使用白环，浅色背景使用黑环，绿点保持纯色。面板跟随应用配色，托盘跟随 Windows 任务栏配色。
- 首次配对使用主电脑连接页；已配对手机直接进入当前对话，设置和项目通过手机返回键回到对话，保留正在编辑的消息。
- 手机优先显示对话文字，按需切换画面；支持项目和对话切换、回复中排队、手机文件上传。
- 设置提供开机自启、外观、版本更新和联系与支持。

## 程序与源码

- `ChatGPTRemote.exe` 是 Windows x64 独立程序。
- `ChatGPT-Remote-v1.2.8-source.zip` 提供同版本源码、构建入口和开发说明。
- `ChatGPT-Remote-Preview.html` 提供离线预览，可切换主题、尺寸和审批场景。
- `SHA256SUMS.txt` 提供发布文件的 SHA-256。

## 第一次使用

1. 打开独立程序，选择程序文件夹。程序与配对数据保存在这里，安装后会登记到 Windows 的“已安装的应用”。
2. 电脑安装并登录 Tailscale，打开 ChatGPT 并登录。当前独立版的远程入口依赖电脑上的 Tailscale。
3. 在电脑另行启用 Funnel：`tailscale funnel --bg --https=8443 http://127.0.0.1:8765`。首次可能需要在 Tailscale 页面确认启用条件；Rm 目前不会自动完成这一步。
4. 打开 Remote 首页，启动服务。首次启用会配置当前用户的后台任务。
5. 手机扫描 Rm 提供的完整连接二维码，再输入配对码并选择窗口。Funnel 模式下手机只需浏览器，不必安装 Tailscale，也不必登录电脑的 Tailscale 账号。

需要 64 位 Windows 10/11 和 Microsoft Edge WebView2。下载 EXE 不会自动建立公网入口；源码中的 `WindowsAgent/setup_funnel_windows.bat` 可完成上述 Funnel 配置。请使用自己的电脑与账号，不使用作者的连接网址。

当前公网路径是“手机浏览器 → Tailscale Funnel 中继 → 电脑上的 Tailscale → Rm → ChatGPT 窗口”。网页、操作接口和画面流由电脑提供，GitHub 只分发程序与更新。服务显示运行中，不代表公网入口已就绪；电脑经 Tailscale 内网能打开，同样不能替代手机网络的实际检查。

## 从源码运行

需要 64 位 Python 3.10 或更新版本、PowerShell 7。先执行 `WindowsAgent/setup_desktop.ps1 -InstallDependencies`，再打开生成的快捷方式。源码运行数据在 `WindowsAgent/data`，依赖和缓存放在 `_wip`。源码更新使用源码包或 Git；内置程序替换只适用于独立 EXE。

## 画面采集

默认优先使用 Windows Graphics Capture（GPU 路径，窗口内容不变时不出帧），初始化失败或多窗口同名时回退到原有的 GDI `PrintWindow`。最小化时文字继续读取原有线程记录；打开画面或执行输入时恢复所选窗口并等待有效尺寸，不改变配对。需要安装 `windows-capture` 与 `numpy` 后生效，未安装时保留 GDI。`RM_CAPTURE=screen` 可强制 GDI，用于排查与对比。

实测（1555×1022 窗口，10 fps 配置）：GDI 采集 63.5 ms，WGC 采集 8.6 ms。

## 数据

独立程序的配对、窗口选择和访问密钥保存在所选程序文件夹的 `_data/`；源码模式保存在 `WindowsAgent/data/`。运行缓存与更新恢复材料位于 `_wip/`，独立程序的手机上传文件属于 `_data/`。更新保留配对和设置。对话正文不写入程序日志；发布包不包含本机配对、密钥或运行数据。

本机 Codex 对话从原有 `.codex/state_*.sqlite`、`thread_history_*.sqlite` 和 `queue_*.sqlite` 只读取得，保留原生角色、消息编号和轮次状态；项目重复打开复用网页内缓存。公开思考摘要和工作记录按用户插话分段折叠，正文通过 markdown-it-py 解析段落、表格、列表、标题、代码及链接。历史图片通过当前对话的不透明引用按需读取，文件必须仍存在于电脑；普通文件引用可查看文字或 PDF。输入、发送及附件附加通过桌面原生控件完成；其它可访问界面继续使用辅助功能读取。

超长对话或剪贴板被占用时，原生输入压力检查仍有读取超时或文字回读失败。遇到无法确认的发送会保留手机草稿并阻止自动重发。
