## 手机操作

- 设置、项目与对话、模型、画面、帮助、配对及确认共用底部弹层。输入框加号直接调起浏览器的附件选择器。设置里的「电脑」组用于切换控制窗口和返回设备首页。
- 队列编辑直接回填输入框。输入框为空时可取回电脑草稿继续写，电脑仍保留原稿直到用户发送。相同内容可以直接发送；两端内容不同时通过「草稿」胶囊打开详情，可合并或明确替换后发送。网页按会话保存文字与待发送附件，刷新和切换后恢复。
- 手机本次选择的常见图片使用缩略图，上传及附加到电脑后仍可点开预览。历史消息的本地附件、正文中的本地图片引用也可预览，原文件必须仍在电脑上。图片按需读取并缓存，发送完成或离开连接时释放本次上传资源。
- 正常进度说明保持可见；说明之间的公开思考摘要和工具动作默认折叠，摘要按实际操作显示图标与标签，用户可手动展开。插话后的内容保留原顺序。
- 空输入遇到电脑正在回复且提供原生停止动作时，发送键显示停止方块。输入文字或附加文件后，同一按键用于发送或排队。排队消息在输入框上方自然展开，可直接引导、删除或编辑。队列暂停时显示「继续」。
- 点设置左侧的电脑图标打开所选窗口。虚拟鼠标跟随触摸，单指轻点是左键，双指轻点是右键。点击前核对最新画面和窗口位置。需要放大时可点画面右上角。
- 当前对话收到审批或问卷时，输入区显示处理入口。问卷提供电脑支持的单选、复选、下一步和提交。其他对话的待处理提示取自电脑侧栏，在全局通知中点「查看」可打开待处理列表。
- 深色面板和深色任务栏使用白底黑字 Rm，浅色用黑底白字。面板和通知区域各自跟随对应配色。

模型名称按自然宽度排列，首尾循环，两侧渐隐。原生风格滑杆只显示当前强度名称，拖动时连续跟随，松手吸附；选择另一个模型时，立即预览该模型支持的档位。模型、思考档位或快速模式有变动时，右上角出现「应用」。一次提交所选项目，电脑确认后更新已应用名称。快速模式生效后，输入框的模型名左侧显示闪电。每次打开重新读取当前账号的原生选项，提交时再次核对电脑。

复杂提醒位于顶栏下方，与输入框等宽。发送状态、回答和草稿入口使用输入框上方 8px 处的横向小胶囊，高 28px。设置和项目面板覆盖输入框，外圆角统一为 25px。

## 连接恢复

- WebSocket 握手和心跳超时后释放旧连接并按退避重建。期间的新操作走现有 HTTP 接口。已提交动作按原消息编号核对回执。
- 切换对话通过 HTTP 发出一次，保留现有同步连接直到窗口版本变化。切换回执丢失时，核对电脑列表中的当前对话。
- 文字流中断时转为定期读取完整快照，并尝试恢复增量流。同一对话保留消息节点、阅读位置和草稿。浏览器离线或进入后台时释放媒体和控制连接，恢复网络或回前台时重新读取状态。
- 新的电脑服务实例重新同步窗口和对话版本，迟到的旧实例数据被忽略。发送回执按设备保存摘要，重启后继续只读核对，确认结果后清理对应草稿。
- 入口授权和设备配对分开处理。入口需要重新授权时提示重新打开电脑提供的连接地址。确认设备令牌失效时进入配对。
- ChatGPT 窗口最小化时继续同步已识别的对话文字。打开电脑画面或使用原生输入时，Remote 恢复该窗口并等待尺寸有效。
