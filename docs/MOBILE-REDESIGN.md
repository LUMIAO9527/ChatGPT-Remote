# ChatGPT Remote 手机端

日期为 2026-11-06。产品页面来自 `WindowsAgent/web/index.html`。用 `tools/build_review.py` 生成当前代码的离线演示。

## 手机操作

- 设置、项目与对话、模型、帮助、配对及确认共用底部弹层。模型、电脑提供的推理强度和快速模式在同一层操作。输入框加号直接调起浏览器的附件选择器，选择来源由手机浏览器提供。设置里的「电脑」组用于切换控制窗口和返回设备首页。
- 队列编辑直接回填输入框。输入框为空时可取回电脑草稿继续写，电脑仍保留原稿直到用户发送。两端内容不同时，发送触发输入框旁的草稿卡，可合并或替换后发送。
- 电脑画面在输入框上方展开。只有当前对话检测到可处理的电脑请求时，输入区才显示处理入口。对话过程用细竖线组织，当前步骤有轻微动效，最终回答使用正文样式。
- 空输入遇到电脑正在回复且提供原生停止动作时，发送键显示停止方块。输入文字或附加文件后，同一按键用于发送或排队。排队消息在输入框上方自然展开，可直接引导、删除或编辑。队列暂停时显示「继续」。
- 从设置打开电脑画面后，画面显示在对话和输入区之间。需要更大画面时可点画面右上角全屏。
- 对话收到可识别的电脑审批或选择请求后，输入区显示入口。审批卡集中显示请求说明、命令和电脑提供的决定。两项式审批并排呈现「拒绝」和「允许一次」。普通选项、单选与勾选调用当前窗口原生可访问动作。点选时核对窗口版本、会话、请求摘要与按钮身份。
- 深色面板和深色任务栏使用白底黑字 Rm，浅色用黑底白字。面板和通知区域各自跟随对应配色。

模型名称按自然宽度排列，相邻名称间隔 14 px。居中名称对应选中模型，首尾循环，文字向两侧逐渐透明。透明边界随上方档位名与闪电图形对齐。思考强度滑杆高 12 px，支持拖动预览与松手落档。手机操作与错误统一由状态浮层展示，打开弹层时浮在其上方，关闭后移到主页面顶部。

## 连接恢复

- WebSocket 握手和心跳超时后释放旧连接并按退避重建。期间的新操作走现有 HTTP 接口。已提交动作按原消息编号核对回执。
- 切换对话通过 HTTP 发出一次，读取暂停到操作结束。已有对话的切换回执丢失时，核对电脑列表中的当前对话。
- 文字流中断时转为定期读取完整快照，并尝试恢复增量流。同一对话保留消息节点、阅读位置和草稿。浏览器离线或进入后台时释放媒体和控制连接，恢复网络或回前台时重新读取状态。
- 新的电脑服务实例重新同步窗口和对话版本，迟到的旧实例数据被忽略。重启后如果无法核对上一条发送结果，手机保留文字并提供「保留为草稿」。
- 入口授权和设备配对分开处理。入口需要重新授权时提示重新打开电脑提供的连接地址。确认设备令牌失效时进入配对。

## 复现

- 在浏览器打开 `ChatGPT-Remote-Preview.html`，可用「回复与排队」「电脑审批」「首次配对」等模拟场景。示例配对码为 246810。
- 源码回归使用 `Verify.ps1`。启用原生测试开关时，`WindowsAgent/tests/test_uia_native.py` 用独立 Edge 测试窗口验证 UIA。
- 公网实际连接继续使用已配置的入口。Mate 80 上的真实 ChatGPT/Codex 弹窗、输入法和蜂窝网络仍待实测。
