# ChatGPT Remote 1.0.0 手机端

日期为 2026-11-06。产品页面来自 `WindowsAgent/web/index.html`，离线演示入口为 `ChatGPT-Remote-Preview.html`。

## 手机操作

- 设置、项目与对话、模型与附件、电脑草稿、帮助和配对从底部打开。面板高度随可视视口变化，较长内容在面板里滚动。点击遮罩、关闭键或使用浏览器返回即可回到原处。
- 空输入遇到电脑正在回复且提供原生停止动作时，发送键显示停止方块。输入文字或附加文件后，同一按键用于发送或排队。暂停队列的「继续」保留在队列区。
- 从设置打开电脑画面后，画面显示在对话和输入区之间。需要更大画面时可点画面右上角全屏。
- 对话收到可识别的电脑审批或选择请求后，输入区显示入口。审批卡集中显示请求说明、命令和电脑提供的决定。两项式审批并排呈现「拒绝」和「允许一次」。普通选项、单选与勾选调用当前窗口原生可访问动作。点选时核对窗口版本、会话、请求摘要与按钮身份。电脑画面模式也提供「电脑弹窗」入口用于主动读取。
- 深色面板和深色任务栏使用白底黑字 Rm，浅色用黑底白字。面板和通知区域各自跟随对应配色。

## 连接恢复

- WebSocket 握手和心跳超时后释放旧连接并按退避重建。期间的新操作走现有 HTTP 接口。已提交动作按原消息编号核对回执。
- 文字流中断时转为定期读取完整快照，并尝试恢复增量流。同一对话保留消息节点、阅读位置和草稿。浏览器离线或进入后台时释放媒体和控制连接，恢复网络或回前台时重新读取状态。
- 新的电脑服务实例重新同步窗口和对话版本，迟到的旧实例数据被忽略。重启后如果无法核对上一条发送结果，手机保留文字并提供「保留为草稿」。
- 入口授权和设备配对分开处理。入口需要重新授权时提示重新打开电脑提供的连接地址。确认设备令牌失效时进入配对。

## 复现

- 在浏览器打开 `ChatGPT-Remote-Preview.html`，可用「回复与排队」「电脑审批」「首次配对」等模拟场景。示例配对码为 246810。
- 源码回归使用 `Verify.ps1`。启用原生测试开关时，`WindowsAgent/tests/test_uia_native.py` 用独立 Edge 测试窗口验证 UIA。
- 公网实际连接继续使用已配置的入口。Mate 80 上的真实 ChatGPT/Codex 弹窗、输入法和蜂窝网络仍待实测。

## 本轮验收

- Node 网页回归 163 项通过。Windows Python 回归运行 265 项，其中 257 项通过，8 项按环境或开关跳过。
- 单独运行的 Edge 原生 UIA 测试通过，覆盖内联审批和对话框选项的发现、读取、显式点选和回读关闭。网页 `dialog` 的 Windows UIA 类型参考 [Chromium 角色映射](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/ui/accessibility/platform/ax_platform_node_win.cc#1037)。
- Chromium 使用本机模拟 Agent 实测配对、弹层、停止与继续、断网恢复和 HTTP 回退。窄屏检查使用 320×342 视口，深浅色检查读取了实际面板的 Rm 填色。离线预览的模拟审批可完整点选。
