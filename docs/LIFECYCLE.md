# 使用、更新与卸载

## 程序和源码

普通使用选择 `ChatGPTRemote.exe`；源码包用于开发和自行构建。两者使用同一套界面与连接协议。独立程序依赖 Windows 自带的计划任务、PowerShell、.NET Framework，以及 WebView2；不需要用户安装 Python。

第一次打开独立程序会先选择程序位置，确认后才建立安装记录并登记 Windows 卸载入口。保留下载的原程序只用于再次打开已安装位置；日常运行打开所选位置的程序即可。程序的 `_data` 保存配对、访问密钥、窗口选择和外观设置；`_wip` 保存缓存、日志、更新与恢复材料。

首次连接：电脑安装并登录 Tailscale，在电脑启用 `tailscale funnel --bg --https=8443 http://127.0.0.1:8765`，并在首次配置时完成 Tailscale 要求的启用确认。源码附带的 `WindowsAgent/setup_funnel_windows.bat` 执行同一配置；只下载独立 EXE 的用户需另行执行这一步。电脑登录 ChatGPT，在 Rm 首页启动服务，再由手机扫码并输入配对码。Funnel 模式下手机只需浏览器，不要求安装 Tailscale 或登录电脑的 Tailscale 账号。

Funnel 是公网 HTTPS 入口，Tailscale Serve 是私网入口，两者不可混写为同一种使用方式。当前独立版尚未提供自动建立公网入口或切换同网直连的完整向导。扫码链接还包含访问入口所需的信息，直接输入不含这些信息的网址时，浏览器可能显示“连接电脑”的引导页。

单击托盘打开面板，再次单击收起；退出管理面板后，后台连接可继续运行。电脑后台在线与公网可达分别检查：公网入口故障可能发生在网页加载之前。重载入口或重启 Tailscale 后，需等到实际 HTTPS 请求成功，才可认定连接恢复；重启 Tailscale 会短暂影响该电脑上的其他 Tailscale 服务。

## 更新

在“设置 → 版本更新”检查、下载，再选择“重启并更新”。程序从固定 GitHub 仓库读取正式版，校验下载大小和 SHA-256，保留 `_data`。更新器等待当前程序与后台退出，再替换程序；新版窗口准备完成、需要恢复的后台已启动后，才确认更新成功。启动失败会重试并尝试回退到上一个程序。

独立入口将校验过的运行组件缓存在 `_wip/runtime/<版本与摘要>`，重复启动复用同一份组件，每次运行的临时目录位于 `_wip/run`。入口退出时收回其组件进程；更新器独立运行，等待入口退出后继续安装。当前安装的后台任务为 `ChatGPTRemote-Agent` 与 `ChatGPTRemote-Tray`，旧任务名称只用于迁移兼容。

有消息正在发送或等待确认时，维护操作会要求先确认结果。下载可以取消；下载或准备失败时，现用程序继续保留。网络不可用不影响已安装功能。源码运行可以查看版本，更新源码使用 Git 或源码包；不会尝试替换 Python 解释器。

## 从 0.17.x 及以前的源码版迁移

先在旧版停止后台服务并退出托盘。打开新独立程序，完成位置选择后，进入“设置 → 使用说明 → 导入旧版配对与设置”，选择原来的项目文件夹。导入会核对旧后台任务归属和停止状态，逐文件复制配对、访问密钥、窗口选择与设置，再移除旧版计划任务；原数据和源码保留。当前程序已有配对或设置时，导入会停止，不覆盖已有数据。

旧版源码停止后台使用 `WindowsAgent/manage_background.ps1 -Action Stop`；退出托盘使用菜单“退出管理程序”。导入前不要重新启用旧版服务。迁移后在新程序首页启动服务，手机继续使用原来的 Tailscale 入口。

## 卸载与重新安装

入口：“设置 → 卸载程序”，或 Windows“设置 → 应用 → 已安装的应用 → ChatGPT Remote → 卸载”。两者打开相同确认页面。默认保留配对与设置；关闭“保留配对与设置”才会清除此程序的数据。

卸载会停用并移除属于当前安装的后台任务、Windows 卸载登记、主程序与指定运行缓存。使用文件范围清单，不递归删除整个安装目录；用户放入的其他文件、源码、ChatGPT 本身和聊天记录不属于卸载范围。保留数据时，下次安装到原文件夹可继续使用。

源码版先停止服务并退出托盘，核对计划任务 `ChatGPTHarmonyRemote-Agent`、`ChatGPTRemote-Tray` 的操作确实指向该项目后再移除。需要保留配对时，保留 `WindowsAgent/data`。应用内的独立程序卸载器不会删除源码目录。

## 构建

运行根目录 `Build-Release.ps1`。构建依赖按 `WindowsAgent/requirements-build.txt` 固定版本安装在项目 `_wip/build`，临时文件、打包缓存和输出分别保存在 `_wip`。已有依赖可通过 `-DependencyPath` 指定。原生更新器从 C# 源码编译；独立程序发布前执行资源自检、Python 与网页回归，并检查首次使用、更新和卸载页面。

运行数据、配对密钥、系统任务快照与签名材料不得放入源码包或发布附件。
