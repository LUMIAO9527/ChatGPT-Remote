# ChatGPT Remote 界面

桌面面板沿用 ChatGPTnx v1.6.0 的尺寸与设计令牌：312×458 逻辑像素、16 像素外壳与卡片圆角、42 像素设置行、按行高 3/8 计算的控件圆角。原生区域、玻璃背景和 HTML 使用同一尺寸与 DPI 比例。

主页直接展示连接二维码、配对码、电脑名称、连接地址、当前窗口和已配对设备。窗口直接选择，设备管理在原行展开。版本信息放在更新页。

每次展开托盘面板回到首页；离开设置、返回设置时收起外观展开项。外观包含配色和材质。导航与原地展开使用 ChatGPTnx 的时长和缓动尺度，遵循系统的减少动画偏好。

联系与支持使用咨询、QQ 联系与打赏卡片的结构。更新页使用产品标识、当前版本、GitHub 项目、主操作和更新状态的结构，说明按需展开。

界面启动前预备，隐藏后保留。隐藏期间停止页面轮询并清除配对码，状态请求合并；设置写入串行处理，界面即时响应，较旧的读取不能覆盖新的选择。

`WindowsAgent/desktop_ui.py` 将本地资源组装为独立文档；`WindowsAgent/build_desktop.py --preview` 从同一文档生成根目录的离线预览。预览只使用示例数据。

Windows 11 的玻璃使用系统 [Desktop Acrylic](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type)；兼容路径使用带几何裁剪的背景宿主。系统关闭透明效果或使用高对比度时显示纯色。
