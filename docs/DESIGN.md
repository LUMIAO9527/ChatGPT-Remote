# ChatGPT Remote 界面

手机队列入口放在输入区。队列行沿用原生排列：消息预览、引导、删除图标、更多图标；编辑收在更多菜单。图标保留可访问名称和触摸范围，点击预览展开全文。暂停状态与继续入口来自电脑原生控件；执行后回读，结果不明时保留提示并提供查看画面。

公开过程说明直接进入消息区，公开思考摘要与工具活动保持折叠。目录按真实来源排除内部审查任务，并保留当前窗口提供的原生入口。同一对话重连保留消息元素、展开状态和阅读位置。

电脑管理窗口与手机网页组成同一个产品。外壳、字体层级、浅深配色、玻璃材质、开关和设置层级沿用 ChatGPTnx；手机连接首页按 DSH Connect 原生 `ConnectionViews.ets` 的布局组织：产品栏、主电脑标题、电脑插画卡片、连接主操作和恢复选项。两端使用同一 Rm 品牌与控件规则，手机按触摸尺寸放大。连接入口保留蓝色主操作，长对话使用中性色和紧凑阅读区。

桌面面板保持 ChatGPTnx 的 312×458 逻辑像素；外壳及卡片 16px、42px 设置行使用 15.75px 圆角。原生区域、玻璃背景和 HTML 使用同一尺寸与 DPI 比例。手机主电脑卡片 27px、配对表单 24px、设置分组 20px、连接主按钮 15px。

首次配对显示连接页，从“输入配对码”进入表单。配对完成与后续重新打开直接进入对话主界面，可恢复对话或画面偏好。设置、项目、草稿和输入选项通过独立页面片段加入浏览器返回栈，关闭或手机返回后回到对话。连接页位于“设置 → 我的主电脑”，保留草稿、附件和队列，暂停文字和画面流。离开设置后收起其展开项。

对话标题入口使用 14px 圆角点击区和同一套 SVG 下箭头，触摸按压显示柔和底色。项目面板按项目直接分组并支持搜索，本地目录提供完整条目，展开与重复打开使用页面内缓存。

缓存项目的展开独立于发送和后台读取；空项目展开后显示空状态。同一电脑窗口的状态版本更新时保留目录和展开位置，在后台校对新目录；切换窗口或服务实例时重新读取。目录中的操作目标经过新状态校验后才执行，项目折叠本身只改变手机显示。

主页直接展示连接二维码、配对码、电脑名称、连接地址、当前窗口和已配对设备。窗口直接选择，设备管理在原行展开。版本信息放在更新页。每次展开通过通知图标标识向 Explorer 重新读取坐标，并按目标显示器的 DPI 定位。

每次展开托盘面板回到首页；离开设置、返回设置时收起外观展开项。外观包含配色和材质，导航与原地展开遵循系统的减少动画偏好。手机设置、项目列表和输入选项共用页面层级、返回与关闭规则。

联系与支持使用咨询、QQ 联系与打赏卡片的结构。更新页使用产品标识、当前版本、GitHub 项目、主操作和更新状态的结构，说明按需展开。

界面启动前预备，隐藏后保留。隐藏期间停止页面轮询并清除配对码，状态请求合并；设置写入串行处理，界面即时响应，较旧的读取不能覆盖新的选择。

`WindowsAgent/desktop_ui.py` 将本地资源组装为独立文档；`WindowsAgent/build_desktop.py --preview` 从同一文档生成根目录的离线预览。预览只使用示例数据。

玻璃沿用 ChatGPTnx 的 HostBackdropBrush 与 CompositionRoundedRectangleGeometry 组合，背景本身按 16 像素半径裁剪。轻量 C++/WinRT 宿主由同一 UI 线程创建和释放；主窗口直接应用同半径的区域。系统关闭透明效果或使用高对比度时显示纯色。

Rm 与 ChatGPTnx 的 Nx、DSH Connect 的 Cn 共用 32 单位网格、R10 底板和 2.8 单位圆头笔画。深色采用 #171717 底板与白字，浅色采用白底、#171717 字和细灰边；两套保持相同字形和留白。应用内标识随应用配色，通知区域随 Windows 任务栏配色自动切换。圆形由系统遮罩适配，主资源使用圆角方形。

WindowsAgent/assets/rm-mark.svg 是唯一图形源；运行 python -B WindowsAgent/desktop_icon.py 生成浅／深 SVG 与各九种尺寸的 ICO。desktop.ico 保留深色标准版本，供快捷方式和不支持主题切换的入口使用。

已识别的桌面对话优先从本机结构化历史读取，真实消息类型和轮次决定角色、正文与活动；思考只展示公开摘要。原始数据库使用只读连接。原生控件负责输入和发送，空输入通过编辑器的占位结构判断，文件附加等待输入焦点生效并通过独立状态查询确认，响应丢失只重读结果。

普通文字使用一次原生 Unicode 输入，换行采用编辑器的软换行，确认完整内容后才触发发送按钮。长文字优先粘贴；剪贴板失败且输入回调尚未执行时，改用原生输入。输入已开始后按现有回读确认处理。剪贴板读取和保存覆盖整个请求的异常处理，暂时占用时有限等待；前台焦点在输入前变化时恢复一次，并重新核对对话和空草稿。

网页 SVG favicon 随浏览器浅／深色切换；手机添加到桌面的 PNG 使用深色标准版本。对话遵循电脑端原生的轮次层级：用户消息右对齐，正式回答直接排版；同轮评论、公开思考摘要和网页搜索收在一个活动区域。折叠入口显示原生“用时”状态，箭头位于文字右侧，下方细分隔线连接正文；生成时展示过程，结束后收起，手动展开状态随增量更新保留。思考摘要降低字号和亮度，网页搜索使用独立标识。队列位于输入框上方，用户时间放在元信息栏，复制按钮在回复完成后显示，只复制正文。活动与耗时按结构字段呈现，不增加读取频率。
